# ColorFly Studio

Generador web de paletas de colores aleatorias. Permite elegir cuántos colores generar, consultar sus códigos en HEX o RGBA y conservar colores al crear una nueva paleta.

## Sitio publicado

[Abrir ColorFly Studio](https://caterinacoaloa.github.io/M1-CaterinaCoaloa/)

## Funciones

- Generar paletas de 6, 8 o 9 colores.
- Mostrar los códigos de color en formato HEX o RGBA.
- Bloquear colores para conservarlos al generar otra paleta. Los colores desbloqueados se vuelven a generar.
- Usar controles con etiquetas y navegar mediante teclado con indicador de foco visible.

## Cómo usar

1. Elegí la cantidad de colores.
2. Elegí el formato del código: HEX o RGBA.
3. Pulsá **Generar paleta**.
4. Si querés conservar un color, pulsá **Bloquear** en su tarjeta antes de generar otra paleta.

También podés abrir `index.html` en un navegador para ejecutar el proyecto localmente.

## Tecnologías

- HTML
- CSS
- JavaScript

## Estructura

- `index.html`: estructura de la aplicación.
- `css/style.css`: estilos y diseño adaptable de los elementos.
- `js/script.js`: generación, visualización y bloqueo de colores.
- `assets/`: imágenes utilizadas por el proyecto.
