# Uso de inteligencia artificial

Durante el desarrollo de ColorFly Studio utilicé un asistente de IA como apoyo para resolver dudas, implementar una funcionalidad y mejorar la documentación. Revisé los cambios y comprobé el funcionamiento del proyecto.

## Prompts y resultados

| Prompt utilizado | Resultado |
|---|---|
| “haceme lo de bloqueo de colores” | Se agregó un botón para bloquear o desbloquear cada color. Al generar otra paleta, los colores bloqueados se conservan y los demás cambian. |
| “explicame como hacerlo” | Recibí una explicación sencilla de cómo funciona el bloqueo por tarjeta y de los pasos necesarios para volver a implementarlo. |
| “haceme el readmi mas con palabras de estudiante de full stack” | Se revisó el README para explicar el proyecto con un tono más claro y sencillo. Luego pedí un tono profesional pero simple y se ajustó el texto. |
