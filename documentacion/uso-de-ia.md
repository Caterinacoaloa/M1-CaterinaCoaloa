# Uso de inteligencia artificial

Durante el desarrollo de ColorFly Studio utilicé un asistente de IA como apoyo para resolver dudas, implementar una funcionalidad y mejorar la documentación. Revisé los cambios y comprobé el funcionamiento del proyecto.

## Prompts y resultados

| Prompt utilizado | Resultado |
|---|---|
| “en el index.html tengo una selec con el id colores es eso?” | La IA explicó que ese selector corresponde a la cantidad de colores elegida en la página. |
| “que variable me esta faltando decime el nombre no codigo” | La IA indicó que faltaba una variable para guardar el selector y propuso el nombre `selectorColores`, sin escribir el código por mí. |
| “listo ya cree las variables que sigue no me des codigo” | La IA explicó como siguiente paso agregar el evento del botón y usar el valor seleccionado (6, 8 o 9) para decidir cuántas muestras crear, sin dar código. |
